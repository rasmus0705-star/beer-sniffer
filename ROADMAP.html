1. Projektoversigt

BeerSniffer er en prisaggregator for specialøl. Siden samler priser fra 7 danske ølbutikker og viser samme øl side om side så brugerne kan se hvor det er billigst.

Domæne: beersniffer.dk
Frontend: Statisk HTML/JS hosted på GitHub Pages
Data: data.json (statisk fil i Git, opdateres dagligt)
Repo: github.com/rasmus0705-star/beer-sniffer (branch: master)
Lokalt: C:\Kodning\beer-sniffer
🎯 Nuværende status (maj 2026):
  • 2.300+ unikke øl i databasen
  • 7 butikker indekseret
  • 450+ aktive tilbud
  • Live på beersniffer.dk med GA4 + custom dimensions
  • Looker Studio partner-dashboard klar
  • stats.html privat dashboard med login

Forretningsmodel

  • Affiliate-links via Partner-ads (når brugere klikker "Køb →" registrerer Partner-ads klikket og du får provision)
  • Direkte affiliate-samarbejder mulige med fokus på Brygshoppen, A Good Case, Beershoppen osv.
  • Looker Studio dashboard kan deles med partnere som dokumentation af klik-trafik

6. Matching-algoritmen (grupperingslogik)

Det her er HJERTET af BeerSniffer — det er der vi grupperer samme øl fra forskellige shops. Logikken ligger i app/services/matching.py og bruges af app/services/ingest.py når data gemmes i Supabase.

Algoritmen (8 trin)

  1. Normalisering — ASCII, lowercase, fjern volumen/ABV/separatorer
  2. Synonymer — trippel→tripel, west coast ipa→ipa osv.
  3. Style fingerprint — udtrækker DUBBEL, TRIPEL, IPA, STOUT…
  4. Hård gate: stilarter — to forskellige stilarter må ALDRIG merges
  5. Hård gate: volume — skal matche (tolerance for None)
  6. Hård gate: ABV — max 0.4 procentpoint forskel
  7. Hård gate: bryggeri — forskellige bryggerier blokerer match
  8. Fuzzy score — min(token_set_ratio, token_sort_ratio) + bonuses. Threshold: 85

Eksempler

Westmalle Tripel 9,5% 33clWestmalle Dubbel 7% 33cl❌ Style-gate blokerer

7. Deploy & opdateringsworkflow

Dagligt: opdater priser

Dette er den vigtigste rutine. Den kan køres når som helst — typisk 1 gang dagligt:

Den hurtige måde (dobbeltklik):
Dobbeltklik på opdater.bat i Stifinder. Den:
  1. Aktiverer virtual environment
  2. Kører python build_data.py (scrapes alle 7 shops, ingester til Supabase, eksporterer til data.json)
  3. Pusher data.json til GitHub
  4. GitHub Pages opdaterer beersniffer.dk automatisk på 1-2 min

Manuel udgave i PowerShell

cd C:\Kodning\beer-sniffer
.venv\Scripts\activate
python build_data.py
git add data.json
git commit -m "Daglig opdatering"
git push

Standard kode-ændring (frontend, om-side osv.)

# 2. Commit og push
git add .
git status
git commit -m "Beskrivende besked"
git push

# 3. GitHub Pages deployer automatisk på 1-2 minutter

12. Troubleshooting — hvis noget går galt

🔴 Siden viser ingen øl

  1. Åbn browser console (F12) — er der fejl der?
  2. Test om data.json kan hentes direkte: beersniffer.dk/data.json
  3. Hvis 404: data.json mangler i Git. Push den.
  4. Hvis fejl i JSON: kør build_data.py igen lokalt og push.
  5. Hård refresh i browser: Ctrl + F5

🔴 opdater.bat starter ikke når man dobbeltklikker

  1. Højreklik på filen → Egenskaber → "Fjern blokeringen" (hvis vist)
  2. Eller kør manuelt i PowerShell: cd C:\Kodning\beer-sniffer ; .\opdater.bat
  3. Hvis stadig intet sker: brug manuel kommando i PowerShell (se Deploy-sektionen)

🔴 build_data.py fejler under scrape

  1. Tjek .env findes og indeholder korrekt DB_URL
  2. Test Supabase forbindelse: python -c "from app.database import engine; print(engine.url)"
  3. Test en enkelt scraper lokalt: python -m app.scrapers.brygshoppen
  4. Hvis "Network is unreachable" mod Supabase: brug pooler URL (port 6543 i stedet for 5432)

🔴 En scraper henter 0 items

  1. Test lokalt: python -m app.scrapers.[navn]
  2. Tjek om products.json stadig virker for shoppen i browseren
  3. Shoppen har måske ændret pagineringsformatet

🔴 Forkerte øl merges sammen

Tjek app/services/matching.py. Hvis det er en ny case kan thresholds eller gates skal justeres. Bemærk at build_data.py ikke nulstiller databasen — tidligere matches bliver i Supabase. For helt fresh start: TRUNCATE tabellerne i Supabase Studio og kør build_data.py igen.

🔴 git push fejler med "nothing to commit"

Filerne er allerede committet. Tving deploy: git commit --allow-empty -m "trigger deploy" && git push

🔴 stats.html viser ikke Looker-dashboard

  1. Tjek at embed-URL i USERS arrayet er korrekt
  2. Tjek at Looker-rapporten er sat til "Anyone with the link" eller embed-tilladt
  3. Test embed-URL direkte i en ny browser-tab

🔴 Cloudflare-problemer

DNS opdateringer tager 15 min - 2 timer. Hvis SSL fejler: gå til Cloudflare → SSL/TLS → vælg "Full" mode.

1. Projektoversigt

BeerSniffer er en prisaggregator for specialøl. Siden samler priser fra flere danske ølbutikker og viser samme øl side om side så brugerne kan se hvor det er billigst.

Domæne: beersniffer.dk
API: https://beer-sniffer-production-2a11.up.railway.app
Repo: github.com/rasmus0705-star/beer-sniffer (branch: master)
Lokalt: C:\Kodning\beer-sniffer

Forretningsmodel

  • Affiliate-links via Partner-ads (når brugere klikker "Køb →" registrerer Partner-ads klikket og du får provision)
  • Beer Me er bekræftet på Partner-ads — andre shops scrapes direkte uden affiliate

7. Matching-algoritmen (grupperingslogik)

Det her er HJERTET af BeerSniffer — det er der vi grupperer samme øl fra forskellige shops. Logikken ligger i app/services/matching.py og bruges af BÅDE ingest.py (når øl gemmes) OG beers.py (når øl grupperes til frontend).

Algoritmen (8 trin)

  1. Normalisering — ASCII, lowercase, fjern volumen/ABV/separatorer
  2. Synonymer — trippel→tripel, west coast ipa→ipa osv.
  3. Style fingerprint — udtrækker DUBBEL, TRIPEL, IPA, STOUT…
  4. Hård gate: stilarter — to forskellige stilarter må ALDRIG merges
  5. Hård gate: volume — skal matche (tolerance for None)
  6. Hård gate: ABV — max 0.4 procentpoint forskel
  7. Hård gate: bryggeri — forskellige bryggerier blokerer match
  8. Fuzzy score — min(token_set_ratio, token_sort_ratio) + bonuses for ABV/bryggeri/stil match. Threshold: 85

Eksempler

Øl AØl BResultat
Westmalle Trappist Tripel 9,5% 33clWestmalle Trappist Trippel 0,33 l 9,5%✅ MERGE
Westmalle Tripel 9,5% 33clWestmalle Dubbel 7% 33cl❌ Style-gate blokerer
Mikkeller West Coast IPAMikkeller IPA✅ MERGE (IPA-synonymer)
Pure Oude Gueuze 7% 75clTilquin Gueuze 7,5% 75cl❌ Bryggeri+ABV-gate blokerer

8. Deploy & opdateringsworkflow

Standard kode-ændring

# 1. Lav ændringer i VS Code
# 2. Test lokalt hvis muligt

# 3. Commit og push
git add .
git status                           # Tjek hvad der commits
git commit -m "Beskrivende besked"
git push

# 4. Railway deployer automatisk på 1-2 minutter
# 5. Tjek Railway → Deployments at den viser "Success"

Manuel scrape

Invoke-WebRequest -Uri "https://beer-sniffer-production-2a11.up.railway.app/scrape-all" `
  -Headers @{"x-api-key"='din-nøgle'} `
  -TimeoutSec 900

Automatisk scrape

APScheduler i app/services/scheduler.py kører run_scraper() hver dag kl. 06:00. Den behøver ikke API-nøgle fordi den kører internt på Railway.

Nulstil databasen (sjældent)

Invoke-WebRequest -Method POST `
  -Uri "https://beer-sniffer-production-2a11.up.railway.app/reset-beers?confirm=YES" `
  -Headers @{"x-api-key"='din-nøgle'}
Bagefter SKAL du køre /scrape-all for at fylde databasen igen.

10. Tidslinje — hvad er sket gennem tiden

Fase 1 — April 2026
Lokalt projekt (data.json)

Første version. Scrapers (Brygshoppen, A Good Case, Beershoppen) skrev til data.json som blev SFTP-uploadet til Simply webhotel. Frontend læste filen direkte. Ingen database.

April 2026
Fuzzy matching tilføjet

Første version af cross-shop matching med rapidfuzz.fuzz.ratio threshold 88. Senere udvidet med ABV-boost og token_sort_ratio.

April 2026
Flere scrapers: Best of Beers, Beer Me, Belgiskbryg

Beer Me via Partner-ads XML feed. Belgiskbryg krævede Selenium. Mange normaliseringsforbedringer (danske bogstaver, fjern "trappist", stilart-detektering).

April–Maj 2026
UI-features:

Favoritter via localStorage, filterpræferencer huskes, Top 10 tilbud sektion, fragt-tooltip, Google Analytics tracking.

Maj 2026 — STOR migration
Fra Simply til Railway + Supabase + GitHub Pages

FastAPI deployet på Railway. PostgreSQL database på Supabase (gratis tier). Frontend flyttet til GitHub Pages. Cloudflare som CDN/DNS foran. Simply webhotel opsagt — kun domænet beholdt.

Maj 2026
API-paginering implementeret

/beers med page/limit i stedet for at sende alle på én gang. Alle filtre (deals_only, alcohol_free, smagekasse, beer_types, min/max_price, abv_min/max) flyttet til API i stedet for at filtrere lokalt på de 50 hentede.

Maj 2026
Sikkerhed: API-nøgle på scrape-endpoints

SCRAPE_API_KEY environment variable. Cookiebot på Free plan.

Maj 2026
APScheduler — daglig automatisk scrape kl. 06:00

Belgiskbryg fjernet fra scheduler fordi Selenium ikke kører på Railway.

November 2026
Robust matching v2 + Øltanken

Ny matching.py som fælles utility for ingest og beers. Style fingerprint som hård gate (Dubbel kan ALDRIG merges med Tripel). Bryggeri som hård gate (Pure Oude Gueuze ≠ Tilquin Gueuze). Threshold hævet fra 82 → 85. Øltanken-scraper tilføjet (oltanken.dk).

November 2026
Reset-endpoint

/reset-beers tilføjet for at kunne genopbygge databasen fra scratch med den nye matching.

11. Daglig drift & vedligehold

Ugentligt

  • Tjek Railway → Usage — er forbruget under $5?
  • Tjek Railway → Logs en gang — kører den daglige scraper?
  • Tjek beersniffer.dk — vises der friske priser?
  • Tjek Google Analytics — er der trafik?

Månedligt

  • Tjek Search Console for fejl
  • Tjek at scrapers stadig virker (kan ændre sig hvis shops opdaterer deres sider)
  • Overvej om der er nye shops at tilføje

Hvis Railway giver advarsel om forbrug

Cache-TTL i beers.py kan øges fra 3600 (1 time) til 7200 (2 timer). Eller daglig scrape kan flyttes til hver 2. dag.

12. Troubleshooting — hvis noget går galt

🔴 Siden viser ingen øl

  1. Tjek om Railway viser "Online" → railway.app
  2. Test API direkte: https://beer-sniffer-production-2a11.up.railway.app/stats
  3. Hvis "Internal Server Error": tjek Railway Logs for fejl
  4. Hvis API svarer men frontend ikke viser noget: tjek browser console (F12)

🔴 Railway giver "secret postgresql not found"

DB_URL er ikke sat korrekt. Gå til Railway → Variables og verificer at DB_URL findes med fuld Supabase connection string. Husk %40 i stedet for @ i passwordet.

🔴 "Network is unreachable" i Railway logs

Supabase fri-tier blokerer IPv6. Brug pooler URL i stedet:
postgresql://postgres.PROJECT-REF:PASSWORD@aws-0-eu-west-1.pooler.supabase.com:6543/postgres

🔴 En scraper henter 0 items

  1. Test lokalt: python -m app.scrapers.[navn]
  2. Tjek om products.json stadig virker for shoppen
  3. Hvis CAPTCHA: scraperen kan ikke længere bruges

🔴 Forkerte øl merges sammen

Tjek app/services/matching.py. Hvis det er en ny case kan thresholds eller gates skal justeres. Kør /reset-beers + /scrape-all for at genopbygge med opdateret logik.

🔴 git push fejler med "nothing to commit"

Filerne er allerede committet. Tving deploy: git commit --allow-empty -m "trigger deploy" && git push

🔴 Cloudflare-problemer

DNS opdateringer tager 15 min - 2 timer. Hvis SSL fejler: gå til Cloudflare → SSL/TLS → vælg "Full" mode.

13. Fremtidige ideer

Quick wins

  • Genskab Beer Me-scraper via Partner-ads XML feed (fungerede tidligere)
  • Tilføj flere danske ølshops (rookiebeers.com har en liste)
  • IBU-data hvis der findes en kilde

Større features

  • Brugerlogin — Supabase Auth (gratis op til 50.000 brugere)
  • Prisalarm via email — modellen PriceAlert findes allerede
  • Pris-historik graf — PriceHistory indsamles allerede; mangler kun frontend-graf
  • Mobil-app — React Native eller PWA-installation

Skalerings-overvejelser

  • Hvis database vokser kraftigt: opgrader Supabase eller migrer til Railway PostgreSQL
  • Hvis trafik vokser: Cloudflare cache aggressivt på /beers-endpoint
